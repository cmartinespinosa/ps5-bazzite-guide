# PS5 Bazzite Guide

A step-by-step guide to running [PS5 Bazzite Deck](https://github.com/VivaLaVent/ps5-bazzite-deck) on a PS5: from a stock console to Bazzite on the internal M.2, with Decky plugins, tweaks and known fixes.

**Read it here: https://cmartinespinosa.github.io/ps5-bazzite-guide/** ([en español](https://cmartinespinosa.github.io/ps5-bazzite-guide/es/))

## Edit locally

```bash
pip install mkdocs-material mkdocs-static-i18n
mkdocs serve
```

Then open http://127.0.0.1:8000. Pages live in `docs/`: `page.md` is English, `page.es.md` is Spanish. Every push to `main` rebuilds the site.
